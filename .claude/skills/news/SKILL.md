# 新しいお知らせ記事の作成

CLAUDE.md の「提案 → OK → 保存 の流れ」に沿って進める。この手順書は、お知らせ特有の部分を補う。

## 1. 聞き取り

Issueの文章（と貼られた画像）を読み、次のことが分かるか確認する。分からないものだけを質問する。

- 何をお知らせしたいか（メモや箇条書きでよい）
- いつ公開したいか（「すぐ」または日付）。書かれていなければ「すぐ公開でよいですか？」と確認する
- 日時・場所・期間・料金など、記事に必要な事実
- 画像を載せるか（画像が貼られていれば、どこに使うか）

チラシなどの画像だけが貼られて「これでお知らせを」と頼まれたら、画像を読んで内容を文章に起こす。読み取れない部分は推測せず質問する。

## 2. 提案

次の内容をコメントに見やすく表示する。

- **タイトル案**：「案1」「案2」のように番号を付けて2〜3案（30文字以内、内容がひと目で分かるもの）
- **種類**：お知らせ／休業案内／イベント／メディア掲載／採用 のどれか
- **公開日**
- **一覧に出る短い説明**：60文字程度
- **本文案**
- **画像**：使う場合は、どの画像をどこに載せるか

本文の書き方：

- 最初の1〜2文で結論（何が・いつ）を書く
- 日付は「2026年12月29日（火）」のように曜日を付ける（曜日は必ず `python build.py --weekday 日付` で確かめる）
- 期間や日程が複数あるときは、箇条書きか表にする
- 丁寧語で、1文を短く。「〜させていただきます」の連続は避ける
- 最後に、問い合わせ先や補足があれば添える

## 3. ファイルの作成（OKが出てから）

ファイル名：`content/news/公開日-英語の短い名前.md`（半角の英小文字・数字・ハイフンのみ）
例：`content/news/2026-12-01-year-end-holidays.md`

```
---
title: 年末年始休業のお知らせ
date: 2026-12-01
category: 休業案内
status: 公開
summary: 2026年12月29日（火）から2027年1月4日（月）まで休業します。
---
本文をここに書く。

## 見出し

- 箇条書き
```

- `date`：公開日。「すぐ公開」なら `python build.py --check` に表示される今日の日付。未来の日付にすると、その日の朝6時ごろに自動で公開される（予約公開）
- `status`：公開／下書き／非公開。担当者が「まだ公開しない」と言ったときは「下書き」にする
- `end_date`：（任意）この日を過ぎたら自動で表示しなくなる。キャンペーンなど期限のある記事に使う
- 本文の見出しは `##` から始める（`#` は使わない）
- 本文中のリンクや画像は、サイトのトップからの場所で書く（例: `jobs/index.html`、`images/news/photo.jpg`）

### 画像を載せるとき

- `python tools/prepare_image.py /tmp/issue-images/image-1.jpg images/news/2026-12-01-office.jpg` のように整えて保存する
- 記事の先頭に大きく出すなら、項目に `image: images/news/ファイル名` と `image_alt: 画像の説明` を追加する
- 本文の途中に入れるなら `![画像の説明](images/news/ファイル名)` と書く

## 4. 保存

CLAUDE.md の「保存のしかた」に従う。確認用ページのURLは
`https://hisazumi-test.com/kensyo-preview/news/ファイル名.html`
