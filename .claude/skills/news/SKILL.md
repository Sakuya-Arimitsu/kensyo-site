# お知らせ記事の作成・修正

CLAUDE.md の「基本の流れ」に沿って進める。この手順書は、お知らせ特有の部分を補う。

## 1. 聞き取り

最初に次のことを聞く（担当者がすでに書いていれば聞かない）。

- 何をお知らせしたいか（メモや箇条書きでよい）
- いつ公開したいか（「すぐ」または日付）
- 日時・場所・期間・料金など、記事に必要な事実
- 写真や画像を載せたいか

情報が足りなければ、一度に3つまでの質問で補う。

## 2. 提案

次の内容をチャットに見やすく表示する。

- **タイトル案**：2〜3案（30文字以内、内容がひと目で分かるもの）
- **種類**：お知らせ／休業案内／イベント／メディア掲載／採用 のどれか
- **一覧に出る短い説明**：60文字程度
- **本文案**

本文の書き方：

- 最初の1〜2文で結論（何が・いつ）を書く
- 日付は「2026年12月29日（火）」のように曜日を付ける（曜日は必ず計算で確かめる）
- 期間や日程が複数あるときは、箇条書きか表にする
- 丁寧語で、1文を短く。「〜させていただきます」の連続は避ける
- 最後に、問い合わせ先や補足があれば添える

## 3. ファイルの作成

ファイル名：`content/news/公開日-英語の短い名前.md`（半角の英小文字・数字・ハイフンのみ）
例：`content/news/2026-12-01-year-end-holidays.md`

```
---
title: 年末年始休業のお知らせ
date: 2026-12-01
category: 休業案内
status: 公開
summary: 2026年12月29日（火）から2027年1月4日（月）まで休業します。
---
本文をここに書く。

## 見出し

- 箇条書き
```

- `date`：公開日。未来の日付にすると、その日の朝6時ごろに自動で公開される（予約公開）
- `status`：公開／下書き／非公開。担当者が「まだ公開しない」と言ったときは「下書き」にする
- `end_date`：（任意）この日を過ぎたら自動で表示しなくなる。キャンペーンなど期限のある記事に使う
- 本文の見出しは `##` から始める（`#` は使わない）
- 本文中のリンクや画像は、サイトのトップからの場所で書く（例: `jobs/index.html`、`images/news/photo.jpg`）

### 画像を載せるとき

- 画像は `images/news/` に、半角英小文字・数字・ハイフンの名前で保存する（例: `images/news/2026-12-01-office.jpg`）
- 記事の先頭に大きく出すなら、項目に `image: images/news/ファイル名` と `image_alt: 画像の説明` を追加する
- 本文の途中に入れるなら `![画像の説明](images/news/ファイル名)` と書く
- 画像の受け取り方が分からない場合は、担当者に「この会話に画像を添付してください」と頼む

## 4. 既存の記事を直す・取り下げる

1. `content/news/` の記事を、公開日・タイトル・状態の表にして見せ、どれを直すか選んでもらう
2. 直す前と後で、何が変わるかを短く説明してから保存する
3. 取り下げる（消す）ときは、ファイルを削除せず `status: 非公開` にする

## 5. 保存と公開

CLAUDE.md の「保存のしかた」「公開のしかた」に従う。確認用ページのURLは
`https://hisazumi-test.com/kensyo-preview/news/ファイル名.html`
